# 安装 Manual Sim

[English](install.en.md)

一个手动挡练习模拟器：在 2019 款大众 Golf 110TSI（以及另外两台车）上练离合、油门和换档，有坡道路，也有能转向的小城镇。

## 需要什么

- Windows 10 或 11，64 位。不用装 .NET：安装包自带运行时。
- 罗技 G29（方向盘、三个踏板）加 H 档杆，插好，开关拨到 PS3 模式，装好 Logitech G HUB。`config/g29.json` 里的踏板和按钮配置是给 G29 的；暂时不支持其他方向盘。
- 音箱或耳机（发动机声音对控制离合很重要）。

## 安装

1. 把 `ManualSim.zip` 解压到你能写入的地方（例如 `Documents\ManualSim`）。成绩和记录保存在 `config/` 旁边，所以不要放在 `Program Files`。
2. 在 G HUB 里把 G29 的转动范围设成 900°，并关掉它自己的回中弹簧（力反馈由模拟器控制）。
3. 运行 `ManualSim.exe`。第一次会有一个简短的设置：问屏幕宽度、观看距离，并检查音箱。

## 按键

| 按键 | 作用 |
| --- | --- |
| E | 练习、考试和进步 |
| R / H | 重新开始（H：在坡上）或重做练习 |
| M | 坡道路 / 城镇地图（转向） |
| V | 选车 |
| T | 教学模式（离合曲线、语音提示） |
| P | 回放 |
| C | 空调 |
| L | 中文 / English |
| Tab | 调参面板 |
| F2 | 重新做首次设置 |
| F11 | 无边框全屏 |
| Esc | 退出练习，或退出程序 |

用方向盘上的 X 启动发动机。倒档是 H 档杆的第 7 个位置。

## 打包（给开发者）

在仓库里运行：`pwsh scripts/publish.ps1`。结果在 `publish/ManualSim/` 和 `publish/ManualSim.zip`。
