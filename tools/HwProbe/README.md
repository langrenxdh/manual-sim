# HwProbe — M0 硬件验证

> 中文版。英文版见 [`README.en.md`](README.en.md)。两个文件同步维护。

用 SDL3 读 G29 原始输入、驱动力反馈。门槛（design.md）：**离合是独立模拟轴，SDL3 能驱动 G29 力反馈。**

## 准备

1. G29 接 USB 和电源，背面模式开关拨到 PC 用的位置。
2. 装 Logitech G HUB，在 G29 设置里**关闭"合并踏板"**；力反馈强度先拉到 100%，"中心弹簧"关掉。
3. 编译：`dotnet build tools/HwProbe`

运行：`dotnet run --project tools/HwProbe -- <命令>`（下面简写为 `HwProbe <命令>`）。

## 步骤

### 1. `HwProbe list`

记下：名字、VID/PID、`path`、轴/按钮/hat 数量、`haptic` 行、`effects` 行。

### 2. `HwProbe watch --csv watch.csv`

按顺序做，每一步记下哪一行在动：

1. 只踩离合：慢慢踩到底、慢慢松开，重复 3 次。**只能有一个轴动**，油门、刹车两个轴不动。
2. 同样只踩油门，再只踩刹车。
3. 三个踏板一起随便踩一会，确认互不干扰。
4. 档杆依次挂 1、2、3、4、5、6、R（倒档要按下档杆），看 `recent presses` 记下每个档的按钮号。
5. 方向盘上的按钮挨个按一遍（顺序记下来），十字键看 `hat` 行。

按 `q` 退出，把最后打印的 `Summary` 整段贴给我，`watch.csv` 留着（我用来分析量化台阶和噪声）。
顶部的 `poll` 应接近 1000 Hz；`input changes` 是踩动踏板时设备真实的报告频率。

### 3. `HwProbe ffb`

轻握方向盘。先自动扫频 18 档（每档 2 秒），每档记下感觉强度 0–3。扫完进入交互模式：

- 上下键改频率、左右键改幅度：找一下"27 Hz（怠速点火频率）附近手上能感到的最小幅度"。
- `m` 打开调制：每 10 ms 发一个新效果，模拟抖动随负载变化。**感觉是否平顺、有没有断续或卡顿？**
- `g` 打齿短震，`s` 熄火顿挫：各按几次，说说感觉像不像。
- 屏幕上的 `failed` 是否一直为 0，`call time max` 是多少。

### 4. 换后端再跑一次

SDL 默认用 HIDAPI 的 LG4FF 驱动接管 G29。用 `--lg4ff off` 换成 DirectInput（G HUB 驱动）再跑一遍
`list` 和 `ffb`，对比两种后端哪个能用、手感有没有区别。

### 5. 转向力反馈（M9a）：`HwProbe steer`

方向盘会被一个随角度变化的力拉回中间（虚拟弹簧加阻尼），上面叠一层轻微的抖动。转动方向盘，感受回正力是否平顺、没有一格一格的台阶；打到底再放手，看它是否稳稳回到中间而不来回摆。屏幕上每秒打印一次更新频率（应约 100 Hz）、失败次数（应为 0）和最慢一次调用。按 `q` 退出。
